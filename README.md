# AnnoTinder plan

A visual guide to a proposed improvement plan for AnnoTinder: how each part works today (real screenshots) and how it would work afterwards (mockups, sketches and diagrams).

Open `index.html` in a browser, or enable GitHub Pages for this repository to view it online.

Sections: today, the big picture, easier screens, AmCAT integration, data quality, machine coders.

The "after" pictures are mockups. Nothing in them is built, and their numbers are examples.
